# Hands-on Cloud & DevOps Projects

These portfolio labs are being developed to demonstrate practical skills. Each project page describes the intended scope; implementation status should be updated as work is completed.

- [Terraform Azure Infrastructure Lab](terraform-azure-infrastructure/README.md) — modules, environment configuration, state, and Azure resources.
- [Azure DevOps Terraform Pipeline](azure-devops-terraform-pipeline/README.md) — YAML validation, security checks, plan, approvals, and deployment.
- [DevSecOps IaC Scanning](devsecops-iac-scanning/README.md) — Terraform linting, infrastructure security scanning, and secret detection.

**Honest portfolio rule:** label a project as a scaffold until it contains tested code and evidence of a successful run. Never commit state files, secrets, access tokens, or production credentials.
